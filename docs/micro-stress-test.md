# Business & Credit Stress Test

법인오너·부동산 보유 VVIP 고객의 12개월 유동성 방어력을 상담용으로 점검하는 미시 스트레스 테스트입니다.

## 구현 위치

- 계산 엔진: `lib/stress/microStress.ts`
- 시나리오·슬라이더 정의: `lib/stress/microStressScenarios.ts`
- 화면 컴포넌트: `components/stress/BusinessCreditStressTest.tsx`
- 실제 렌더링 위치: `components/StressTestPanel.tsx`

## 핵심 관점

이 모델은 법인이 보유한 채권 가격 변동이 아니라, 법인 자체의 신용도 악화와 회사채·여전채·대출 스프레드 확대가 추가 이자비용, 차환 부담, 운전자본 부담, 유동성 부족액으로 전이되는 경로를 봅니다.

## 포트폴리오 연계

Business Credit 화면 내부에서 Stable / Balanced / Growth를 선택합니다.

- Stable: 민감도 계수 0.75x
- Balanced: 민감도 계수 1.00x
- Growth: 민감도 계수 1.25x

이 계수는 법인 매출 충격을 바꾸지 않고, 고객 포트폴리오가 충격을 흡수하는 능력과 유동성 방어 민감도에 반영합니다.

## 신용등급·스프레드 계산

- 현재 법인 신용등급: AAA / AA / A / BBB / BB 이하 / 무등급
- 등급 하락 가산 스프레드: 1 notch당 50bp
- 조달금리 상승폭 = 회사채·여전채 스프레드 확대폭 + 등급 하락 가산 bp
- 추가 이자비용 = 변동금리 차입금 x 조달금리 상승폭
- 차환 부담 증가액 = 12개월 내 차환 필요 차입금 x 조달금리 상승폭 x 단기차입금 만기집중도

## 시나리오 프리셋

- 충격 없음
- 매출 둔화
- 공실률 상승
- 금리·스프레드 확대
- 신용등급 하락
- 복합 위기
- 매크로 연동형

## 법인 규모 분류

법인 규모는 중소기업 / 중견기업 / 대기업·대규모기업집단으로 선택하며, 간이 판정 결과와 선택값이 다르면 경고를 표시합니다.

- 중소기업: fundingSensitivity 1.20
- 중견기업: fundingSensitivity 1.00
- 대기업/대규모기업집단: fundingSensitivity 0.85

본 분류는 PB 상담용 간이 판정입니다. 실제 법적 분류는 중소기업 확인서, 중견기업 확인서, 공정거래위원회 기업집단 지정 현황 등 공식 확인이 필요합니다.

## 주요 출력값

- 영업현금흐름 감소액
- 매출 감소 기여액
- EBITDA margin 악화 기여액
- 임대수입 감소액
- 추가 이자비용
- 차환 부담 증가액
- 운전자본 부담 증가액
- 추정 조달금리 상승폭
- 신용위험 경고 등급
- 12개월 유동성 부족액
- 유동성 runway
- 리스크 요인별 유동성 부족 기여도
- 유동성 방어 조정안
- 위험등급 Safe / Watch / Danger

## 시각화와 조정안

Business Credit 화면은 매크로 스트레스 테스트의 자산군별 기여도 구조를 법인오너 상담용으로 변형합니다.

- 리스크 요인별 유동성 부족 기여도: 매출 감소, EBITDA margin 악화, 임대수입 감소, 추가 이자비용, 차환 부담, 운전자본 부담을 막대형으로 표시합니다.
- 유동성 방어 조정안: 현금버퍼 목표, 단기채·예금·MMF/RP 방어 버킷, 변동금리 차입금 축소, 12개월 내 만기 차입금 분산, 매출채권·재고 회전 개선 목표를 제안합니다.
- 유동성 runway: 현재 현금버퍼가 스트레스 후 월평균 현금소요를 몇 개월 버틸 수 있는지 표시합니다.

## 모델 한계와 확장

본 결과는 데모 입력값과 PB 상담용 가정 기반 민감도 분석입니다. 실제 제안서에는 법인 재무제표, 차입금 만기표, 담보·보증 조건, 신용평가 보고서, 임대차 계약 현황, 금융기관별 약정 조건 확인이 필요합니다.

외부 API 연동 시에는 기업 재무제표, 신용등급, 회사채·여전채 스프레드, 금리 커브, 부동산 공실률 데이터를 `lib/stress/microStress.ts`의 입력값으로 정규화하면 됩니다. 현재 UI는 API 없이도 동일한 계산 엔진을 쓰도록 분리되어 있습니다.
