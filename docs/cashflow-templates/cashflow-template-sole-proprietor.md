# 개인사업자 현금흐름표 템플릿

## 목적

개인사업자의 사업 매출, 사업비용, 개인 생활비 인출, 부가세/종합소득세, 사업자통장/개인통장 혼용을 구분해 실제 투자 가능 현금을 보수적으로 산출하기 위한 양식입니다.

## 작성 가이드

- 사업자금과 개인 생활자금이 섞여 있으면 자금주체를 "혼용"으로 표시합니다.
- 비용처리 가능 여부는 확정하지 말고 "전문가 확인 필요"로 메모합니다.
- 매출 전체를 개인 가처분 현금으로 보지 않습니다.

## 주의/면책

본 표는 개인사업자 상담 보조용입니다. 비용처리 가능성, 부가세/종합소득세 신고·납부액, 사업자금과 개인자금 구분은 확정 판단이 아니며 세무 전문가 확인이 필요합니다.

## 앱 CashFlow 매핑 규칙

| 템플릿 컬럼 | 앱 필드 |
|---|---|
| 항목명 | `CashFlow.label` |
| 금액(원) + 유입/유출 | `CashFlow.amount` 양수/음수 |
| 일자(YYYY-MM) | `CashFlow.date` |
| 정기/일회 또는 반복주기 | `CashFlow.recurring` |
| 자금주체 | `CashFlow.entity` |
| 계좌유형 | `CashFlow.accountType` |
| 세무·회계 성격 | `CashFlow.category` |
| 메모 | `CashFlow.taxAccountingNote` |
| 앱 반영(Y/N) | N이면 업로드 시 제외 |
