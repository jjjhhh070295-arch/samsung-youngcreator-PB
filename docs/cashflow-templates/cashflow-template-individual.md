# 개인 고객 현금흐름표 템플릿

## 목적

개인 고액자산가의 급여, 생활비, 증여/상속/부동산/금융소득 관련 현금흐름을 상담용으로 정리해 포트폴리오 산출 입력값으로 옮기기 위한 양식입니다.

## 작성 가이드

- 금액은 원 단위로 입력합니다. 유출은 표의 "유입/유출" 컬럼에 "유출"로 표시합니다.
- 세금·회계 성격은 확정 판단이 아니라 상담용 분류입니다.
- 세금 예상액, 증여/상속, 양도소득세는 세무 전문가 확인 필요로 메모합니다.

## 주의/면책

본 표는 PB 상담과 포트폴리오 산출 보조를 위한 입력 양식입니다. 세금·회계·법률 판단을 확정하지 않으며, 실제 신고·납부·비용처리 가능 여부는 세무사/회계사/변호사 확인이 필요합니다.

## 앱 CashFlow 매핑 규칙

| 템플릿 컬럼 | 앱 필드 |
|---|---|
| 항목명 | `CashFlow.label` |
| 금액(원) + 유입/유출 | `CashFlow.amount` 양수/음수 |
| 일자(YYYY-MM) | `CashFlow.date` |
| 정기/일회 또는 반복주기 | `CashFlow.recurring` |
| 자금주체 | `CashFlow.entity` |
| 계좌유형 | `CashFlow.accountType` |
| 세무·회계 성격 | `CashFlow.category` |
| 메모 | `CashFlow.taxAccountingNote` |
| 앱 반영(Y/N) | N이면 업로드 시 제외 |
