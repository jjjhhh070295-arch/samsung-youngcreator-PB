# 법인-대표 연동형 현금흐름표 템플릿

## 목적

법인 고객과 대표 개인 고객을 함께 상담할 때 법인세, 배당 지급, 대표 개인 배당 유입, 종합소득세 예비금이 중복 또는 누락되지 않도록 연결 관점으로 정리하는 양식입니다.

## 작성 가이드

- 법인 지급 행과 개인 유입 행은 둘 다 필요할 수 있으나, 포트폴리오 산출에서 중복 반영되지 않도록 메모에 같은 기준월/키를 남깁니다.
- 법인세 납부 후 실제 배당 가능 재원을 보수적으로 봅니다.
- 지분율, 최대주주 여부, 배당 결의 여부는 상담용 입력이며 확정 법률/세무 판단이 아닙니다.

## 주의/면책

본 표는 법인-대표 연동 상담 보조용입니다. 배당 가능이익, 배당 결의, 가지급금/가수금, 법인세 및 개인 종합소득세는 확정 판단이 아니며 세무사/회계사/변호사 및 내부 컴플라이언스 확인이 필요합니다.

## 앱 CashFlow 매핑 규칙

| 템플릿 컬럼 | 앱 필드 |
|---|---|
| 항목명 | `CashFlow.label` |
| 금액(원) + 유입/유출 | `CashFlow.amount` 양수/음수 |
| 일자(YYYY-MM) | `CashFlow.date` |
| 정기/일회 또는 반복주기 | `CashFlow.recurring` |
| 자금주체 | `CashFlow.entity` |
| 계좌유형 | `CashFlow.accountType` |
| 세무·회계 성격 | `CashFlow.category` |
| 메모 | `CashFlow.taxAccountingNote` |
| 앱 반영(Y/N) | N이면 업로드 시 제외 |
