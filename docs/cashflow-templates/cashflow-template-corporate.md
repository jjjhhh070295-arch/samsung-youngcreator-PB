# 법인 고객 현금흐름표 템플릿

## 목적

법인 자체의 운영자금, 법인세, 부가세, 급여, 배당 지급, CAPEX, 차입금 만기를 분리해 법인 자금 운용 포트폴리오의 유동성 버킷을 산출하기 위한 양식입니다.

## 작성 가이드

- 법인 자금과 대표 개인 자금은 반드시 분리합니다.
- 법인세/배당/CAPEX는 이사회 승인, 회계처리, 세무 검토 필요 여부를 메모합니다.
- 법인 자금 운용 추천은 상담용이며 내부 규정과 전문가 확인이 필요합니다.

## 주의/면책

본 표는 법인 자금 운용 상담 보조용입니다. 세무·회계처리, 이사회 승인, 투자 가능 상품 판단을 확정하지 않으며, 실제 집행 전 전문가 및 내부 컴플라이언스 확인이 필요합니다.

## 앱 CashFlow 매핑 규칙

| 템플릿 컬럼 | 앱 필드 |
|---|---|
| 항목명 | `CashFlow.label` |
| 금액(원) + 유입/유출 | `CashFlow.amount` 양수/음수 |
| 일자(YYYY-MM) | `CashFlow.date` |
| 정기/일회 또는 반복주기 | `CashFlow.recurring` |
| 자금주체 | `CashFlow.entity` |
| 계좌유형 | `CashFlow.accountType` |
| 세무·회계 성격 | `CashFlow.category` |
| 메모 | `CashFlow.taxAccountingNote` |
| 앱 반영(Y/N) | N이면 업로드 시 제외 |
