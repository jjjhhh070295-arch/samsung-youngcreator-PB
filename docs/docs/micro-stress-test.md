# Business & Credit Stress Test

법인오너·부동산 보유 VVIP 고객의 12개월 유동성 방어력을 상담용으로 점검하는 미시 스트레스 테스트입니다.

## 구현 위치

- 계산 엔진: `lib/stress/microStress.ts`
- 시나리오·슬라이더 정의: `lib/stress/microStressScenarios.ts`
- 화면 컴포넌트: `components/stress/BusinessCreditStressTest.tsx`
- 실제 렌더링 위치: `components/StressTestPanel.tsx`

## 핵심 변경

기존의 `크레딧 평가손실`은 법인이 보유한 회사채·여전채 가격 하락을 의미할 수 있어 삭제했습니다. 현재 모델은 법인 자체의 신용등급 하락과 회사채·여전채·대출 스프레드 확대가 차입비용, 차환 압박, 운전자본 부담으로 전이되는 경로를 봅니다.

## 주요 입력값

- 영업: 연매출, EBITDA margin, 영업 레버리지
- 부동산: 연 임대수입, 현재 공실률
- 차입: 총차입금, 변동/차환 차입금, 12개월 만기도래 차입금, 평균 조달금리, 현재 신용등급
- 유동성: 현금 버퍼, 이벤트성 유동성 필요액
- 재무비율: 유동비율, 부채/자기자본, 이자보상배율, 매출채권 회수일, 재고 회전일

## 주요 출력값

- 영업현금흐름 감소액
- 임대수입 감소액
- 시장 스프레드 이자비용
- 신용등급 하락 추가 차입비용
- 운전자본·회수지연 부담
- 12개월 유동성 부족액
- 스트레스 후 유동비율, Debt/EBITDA, EBITDA margin, 회수일

## 포트폴리오 연계

확정된 포트폴리오 라벨 또는 변동성으로 Stable / Balanced / Growth를 감지합니다.

- 안정형: 충격 강도와 차입 스프레드 민감도를 낮추고, 현금성 방어력을 높게 봅니다.
- 균형형: 기준 민감도를 적용합니다.
- 수익추구형: 위험자산 현금화 할인과 차환 압박을 반영해 동일 충격의 민감도를 높입니다.

이 보정은 법인 매출 자체가 포트폴리오 때문에 바뀐다는 뜻이 아니라, PB가 고객 전체 유동성 방어력을 볼 때 포트폴리오의 현금화 가능성과 위험자산 민감도를 반영한다는 뜻입니다.

## 매크로 스트레스 연동

`StressTestPanel`의 매크로 슬라이더 값을 `BusinessCreditStressTest`에 전달합니다.

- 기준금리·10년물 상승: 차입 스프레드 확대, 신용등급 하락 가능성
- 인플레이션·원자재 상승: EBITDA margin 압박, 운전자본 부담
- 원달러 환율 상승: 수입원가·외화성 운전자본 부담

연동 토글을 끄면 Business Credit 자체 프리셋과 슬라이더만 반영합니다.

## API 연동 가능성

현재는 데모 입력값으로 동작합니다. 실제 연동 시 다음 데이터 소스를 연결할 수 있습니다.

- 법인 재무제표: 매출, EBITDA, 차입금, 이자비용, 유동비율, 매출채권·재고 회전일
- 여신/차입 데이터: 만기도래 차입금, 변동금리 차입금, 평균 조달금리
- 신용평가 데이터: 현재 신용등급, 등급별 스프레드 매핑
- 시장 데이터: 회사채 AA-/BBB- 스프레드, 여전채 스프레드, 기준금리, 국고채·은행채 금리
